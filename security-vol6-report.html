⚡ Vol.6 攻击发现的 8 个漏洞

V6-01 CRITICAL
constantTimeEqual 长度侧信道 — 链式漏洞第三次出现
dynamic_firewall.dart 和 license_manager.dart 的 _constantTimeEqual() 仍存在长度侧信道： 当 a.length ≠ b.length 时直接返回 false，攻击者可通过响应时间推断正确密码长度。 这是 Vol.4→Vol.5→Vol.6 第三次出现的链式遗漏——同一种修复模式在不同文件反复遗漏。
📄 dynamic_firewall.dart · license_manager.dart
maxLen 迭代dummy 变量// ignore: unused_local_variable
V6-02 CRITICAL
GET 请求可触发关机/重启/锁屏/自毁 — CSRF 攻击
危险端点 /shutdown、/restart、/lock-screen、/remote-self-destruct 不限制 HTTP 方法。 恶意网页可通过 <img src="http://localhost:9998/shutdown"> 发起 CSRF 关机攻击。 这直接威胁用户的核心安全需求：「不管干什么都不能让我的电脑关机」
📄 http_server.dart
POST 方法强制执行405 Method Not AllowedAllow: POST 响应头
V6-03 HIGH
慢速暴力破解绕过速率限制
_recordSuccess() 完全清除失败记录 (_rateLimit.remove(ip))， 允许攻击者使用数学模式：3 次失败 → 1 次成功 → 重置 → 重复，永不触发封禁。
📄 http_server.dart
failures 减半而非清零blockCount 永不减少双重条件移除
V6-04 HIGH
Linux AES 密钥明文存储 — 加密体系灾难
LicenseManager._getAesKey() 不检查 SecureStorageValidator， 在 Linux 无 libsecret 时 AES-256 密钥被明文写入 JSON 文件，整个加密体系无效。
📄 license_manager.dart
SecureStorageValidator.validate()Linux 内存密钥不明文持久化
V6-05 HIGH
WebRTC DataChannel 无命令过滤 — 远程关机通道
webrtc_connection_service.dart 的 _handleDataChannelMessage() 无任何命令过滤， 恶意连接对端可通过 DataChannel 发送 shutdown/restart 命令直接关机。 又一个威胁「不能让我的电脑关机」核心需求的漏洞
📄 webrtc_connection_service.dart
_allowedCommands 白名单(23)_blockedCommands 黑名单(7)双层命令过滤
V6-06 MEDIUM
OpenSSL -nodes 明文私钥写入磁盘
certificate_manager.dart 使用 openssl req -nodes 标志生成证书， 私钥直接以明文 PEM 写入临时文件，文件恢复工具可获取。
📄 certificate_manager.dart
移除 -nodes-passout file: 保护内存解密覆写删除
V6-07 MEDIUM
UDP nonce 碰撞 + 批量清除重放窗口
32-bit nonce 碰撞概率高（每秒 2^32 次探测即可碰撞）； 每 30 秒批量清除所有 nonce 打开 30 秒重放攻击窗口。
📄 udp_discovery.dart

V6-08 MEDIUM
信令消息无结构验证 — 伪造 SDP/ICE 注入
signaling_client.dart 不验证 WebSocket 消息类型和结构， 恶意信令服务器可注入伪造的 offer/answer/ICE candidate，劫持 WebRTC 连接。

🔍 自检发现的 2 个链式漏洞遗漏

🔗 链式漏洞模式：V6-04 修复了 license_manager.dart 的 SecureStorageValidator 缺失， 但自检发现同样的模式在另外两个安全文件中存在遗漏

SC-01: certificate_manager.dart — TLS 私钥 Linux 明文存储

CertificateManager 使用 FlutterSecureStorage 存储 TLS 私钥， 但不调用 SecureStorageValidator.validate()。在 Linux 无 libsecret 时， TLS RSA-2048 私钥被明文写入 JSON 文件，与 V6-04 修复的 AES 密钥同类漏洞。

SecureStorageValidator 检查Linux 私钥仅驻留内存不持久化到不安全存储
SC-02: dynamic_firewall.dart — HMAC 密钥 Linux 明文存储

DynamicFirewall._ensureFirewallKey() 使用 FlutterSecureStorage 存储 HMAC-SHA256 密钥， 但不调用 SecureStorageValidator.validate()。在 Linux 无 libsecret 时， HMAC 密钥被明文写入 JSON 文件，攻击者可读取密钥伪造合法防火墙验证响应。

SecureStorageValidator 检查Linux HMAC 密钥仅驻留内存不持久化到不安全存储
SC-03: certificate_manager.dart — passphrase 文件清理遗漏

V6-06 修复中 _cleanupTemp() 对 key.pem 做了覆写+删除双重安全清理， 但 passphrase.txt 只做了删除没有覆写。文件恢复工具可能恢复 passphrase 文件， 然后用它解密磁盘上的加密私钥文件。

passphrase 文件覆写+删除与 key.pem 同级安全清理
